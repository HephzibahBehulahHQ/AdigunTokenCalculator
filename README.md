# AdigunTokenCalculator

A browser-only calculator suite from **Hephzibah Behulah · HB Artificial Intelligence**. The owner confirmed full English, German, Yoruba and Nigerian Pidgin interface support and system-font fallback pending official typography.

## Local development
- Node.js 20+ recommended
- `npm install`
- `npm run dev`
- `npm test`
- `npm run build`

Vite bundles static HTML, CSS, JavaScript modules and tokenizer ranks locally. There is no backend, database, analytics, telemetry or runtime CDN. User-entered data is processed in the browser.

## Tokenizer scope
The initial mappings are GPT-4o / GPT-4o mini → `o200k_base` and GPT-4 / GPT-3.5 Turbo → `cl100k_base`. Counts describe the supplied plain text and selected encoding, not total API usage or billing. No other model is claimed as supported.

## Data restraint and disclaimers
World-statistics metrics are intentionally withheld until dated, credible baselines and methodology are verified. Demographic percentages are user-entered, with no invented defaults. BMI, Zakat, Qibla, loan, fuel and sleep outputs include limitations in the interface.
