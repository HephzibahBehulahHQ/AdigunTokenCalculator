# Privacy and data handling

AdigunTokenCalculator is a static, browser-only application. Form values are processed locally in JavaScript and are not intentionally transmitted to a server. The application contains no account, analytics, advertising tracker, remote logging, database or calculation API. Tokenizer code and rank data are bundled with the application rather than fetched from a runtime CDN.

This describes the application code, not hosting-provider processing. A static host may independently process ordinary web request metadata. Avoid entering private information on a public or shared device you do not control.
